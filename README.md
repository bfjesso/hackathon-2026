# Inspiration
We were inspired by clean, sustainable energy sources that can be used to power technology and save the environment.
# What it does
Power Defense is a tower-defense game where you defend against waves of zombies and spend energy wisely.
# How we built it
We used Vite as a build tool, Three.js to render 3D graphics, and Javascript for the game logic.
# Challenges we ran into
We had issues with the frame rate changing the speed of enemies and the game logic.
# Accomplishments that we're proud of
We created a finished game using nothing but Three.js and Javascript for rendering and game logic respectively.
# What we learned
We learned that AI is a great tool for accelerating development as long as you pay close attention to the changes it makes.
# What's next for Power Defense
Power Defense could use different types of zombies, different levels, and more power ups in the future.
